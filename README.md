# 🧩 I am Dad

Cẩm nang toàn diện giúp ba mẹ có con tự kỷ (ASD) tập trung — được xây dựng dựa trên phương pháp TEACCH, ABA, và OT.

## 🚀 Chạy ứng dụng

```bash
npm install
npm run dev
```

Mở trình duyệt tại `http://localhost:5173`

## 📖 Nội dung

| Mục | Mô tả |
|-----|-------|
| 🛋️ Setup phòng học | Hướng dẫn bố trí phòng học 6 khu vực theo phương pháp TEACCH |
| 🎯 Chương trình tập trung | Lộ trình 4 tuần tăng dần tính độc lập |
| 📝 Bài tập & Trò chơi | 12+ hoạt động theo chủ đề động vật |
| 💡 Hiểu hành vi | Giải thích khoa học về echolalia, stimming, prompt dependency |
| 📅 Lịch trình mỗi ngày | Mẫu buổi học 40 phút có cấu trúc |
| 📊 Theo dõi tiến trình | Ghi nhận & theo dõi tiến bộ hàng ngày |
| 📚 Tài liệu tham khảo | Phương pháp, sách, tài nguyên online |

## 💛 Dành cho

Bé trai 6 tuổi, ASD, thích động vật & âm nhạc.
